# Istruzioni per Claude – Night Trap (3DO): sottotitoli in italiano

Progetto di Linobob. crea_patch.py costruisce le ISO sottotitolate (e le patch BPS) dalle ISO originali.

## Regole
- Rispondi in italiano. Chiedi conferma prima di iniziare il lavoro vero e proprio.
- Ogni documento prodotto per l'utente va dato anche in PDF (legge spesso dal telefono).
- Niente dati del gioco nel repository (eseguibili, audio, video, copioni completi): solo strumenti,
  tempi, testi propri e documentazione.
- Licenza MIT. README in italiano e in inglese; tieni aggiornati README e docs con lo stato e le scoperte.
- Prima di provare una modifica sul MiSTer, le ISO 3DO modificate vanno **firmate con 3dt**
  (https://github.com/trapexit/3dt): all'avvio la console controlla blocchi a caso del disco.

## Tool comuni
I tool generici stanno nel repository comune [retro-tools](https://github.com/Linobob/retro-tools);
qui ce ne sono delle copie. Se un tool viene migliorato qui, proponi di riportare la modifica anche lì
(e viceversa). Se nasce un tool nuovo che può servire altrove, **proponi all'utente** di metterlo in
retro-tools e chiedi conferma.
